- `bip-1.webp` — Dự án đang làm / Current Build

The Latest Video card has no static image here: its thumbnail comes from the YouTube link set in `LATEST_VIDEO_URL` in `src/i18n/content.ts`.

Replacing a photo later? Upload a file with the same name and re-deploy the site. Keep it `.webp` and compressed (~80% quality, max ~1200px wide) — photos straight from a camera are typically several MB each.
